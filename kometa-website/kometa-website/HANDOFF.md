# Photo replacement guide — read this first

This project (Kometa website) is code-complete. The only remaining work is swapping a set of
lower-resolution images (screenshotted/extracted from a PDF brochure) for real original files.
Team photos and the hero slider are already original, high-quality uploads — they do **not**
need replacing.

Images must come in as attachments in the chat (there's no other way to get them in) — send them
in small batches (3–4 at a time) across a few messages if you hit an attachment limit.

For each image below: the **destination file** is where it goes in the project, exactly replacing
the existing file at that path. Match by the description, not just the number — the filenames are
generic and a mismatch already happened once before (Mera Bonita's photo was originally swapped
with Dynatek's by mistake), so double-check each one against its label before saving.
